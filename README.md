### Project Overview
<p>
Maintaining independence during everyday activities can
become increasingly difficult for those suffering with cognitive or mental health challenges such as dementia. Tasks
such as remembering personal belongings, following a
daily routine, and preparing to leave the house can become barriers to participating in social and communal
activities, as well as ones independence. This project proposes a wearable backpack assistive system designed to
provide simple and intuitive reminders while helping users
organise tasks for their day. By combining RFID identification, visual feedback, buttons, and audible alerts, the
system aims to support users in completing daily routines
independently while providing peace of mind for carers. <p>


### Proposed Solution 
<p>The proposed solution is an intelligent backpack which
incorporates an RFID based inventory tracking system,
LCD display, physical buttons, and audtitory alerts. Users
will be able to select a predefined daily task or a checklist
using the backpack’s buttons with each of the required
items appearing on the display as a worded and visual aid.
RFID tags attached to important belongings will allow
the backpack to automatically detect whether required
items have been placed inside, with the checklist providing
visual feedback to reflect this. If the user attempts to
leave without a required item, the system can provide an
audible warning. It will also provide regular auditory updates for the user 
about what items are still to be collect or what task they are doing.
The system will therefore combine task
reminders with automatic item verification to reduce the
cognitive load associated with preparing for daily activities
while maintaining a simple and intuitive interface.<p>
